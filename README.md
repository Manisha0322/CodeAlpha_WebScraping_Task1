# CodeAlpha Internship - Web Scraping Task 1

## Project Overview
This project is part of my CodeAlpha Internship. It uses Python to scrape quotes and author names from a website and save the collected data as a CSV file.

## Technologies Used
- Python
- Requests
- BeautifulSoup
- CSV

## Website Used
https://quotes.toscrape.com/

## Project Files
- `scrape.py` – Python script used for web scraping.
- `my_custom_dataset.csv` – Dataset containing scraped quotes and author names.

## How to Run
1. Install Python.
2. Install the required libraries:
   `pip install requests beautifulsoup4`
3. Run the Python script:
   `python scrape.py`

## Output
The program collects quotes and their authors from the website and saves them in `my_custom_dataset.csv`.
